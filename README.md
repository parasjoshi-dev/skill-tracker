# Skill Tracker

A simple JavaScript project to track the skills I'm currently learning.

## Features

- Add skills
- Select a skill category
- Mark skills as Learning or Completed
- Delete skills
- Search skills
- Track total, completed, and learning skills
- Responsive interface

## Technologies Used

- HTML
- CSS
- JavaScript
- DOM Manipulation
- Git & GitHub
- GitHub Pages

## Live Demo

[View Skill Tracker](https://parajoshi-dev.github.io/skill-tracker/)

## What I Learned

This project helped me practice JavaScript fundamentals, DOM manipulation, events, functions, arrays, objects, and dynamic HTML elements.
